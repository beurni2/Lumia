============================================================
DESIRED BEHAVIOR
============================================================

For first-card selection only:

Instead of always selecting `pool[0]`, select from a small quality band around the best candidate using stable creator-id hashing.

Example behavior:

- Let `best = pool[0]`.
- Build a band of candidates whose quality is close enough to best.
- Use stable hash of `creator.id` to choose one candidate from the band.
- Same creator id should always choose the same candidate from the same band.
- Different creator ids may choose different candidates.
- If creator id is missing, fall back to `pool[0]`.
- If band size is 1, fall back to `pool[0]`.
- Only affect the first selected card / first impression slot.
- Do not change selection for subsequent cards unless unavoidable.
- Do not lower validators or include weak candidates.

The intent is to diversify first-card winners across fresh creators while preserving quality.
