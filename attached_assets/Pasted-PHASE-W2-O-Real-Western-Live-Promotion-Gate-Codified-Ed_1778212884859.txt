PHASE W2-O — Real Western Live Promotion Gate + Codified Editorial Rubric

Context:
We discovered an approval semantics mismatch.

Current facts:
- The original Western draft source has 157 entries.
- W2-I promoted the top 100 via an offline W2-D editorial ranker.
- That ranking is only encoded as W2I_DRAFT_PROMOTION_IDS order.
- The ranking rubric/scores are not in the repo.
- W2-L and W2-N did not go through the same W2-D editorial ranking process.
- W2-L and W2-N were ChatGPT-curated, deduped, normalized, tested, and appended directly to APPROVED_WESTERN_PROMOTION_CANDIDATES.
- reviewedBy = PENDING_EDITORIAL_REVIEW does not block runtime selection.
- When LUMINA_W2_WESTERN_APPROVED_ENABLED=true, all 300 entries are equally runtime-selectable.
- The current APPROVED_WESTERN_PROMOTION_CANDIDATES name is misleading: it means staging validated curation rows, not editor-signed production-ready live entries.
- Author-pipeline survival is uneven:
  - W2-I: 79/100 author OK
  - W2-L: 66/100 author OK
  - W2-N: 56/100 author OK

Goal:
Create a real, reproducible editorial promotion gate before any production rollout or more bulk W2 imports.

- reject reasons

  - reject
