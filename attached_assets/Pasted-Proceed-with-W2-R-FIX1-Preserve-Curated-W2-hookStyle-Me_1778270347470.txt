Proceed with W2-R-FIX1 — Preserve Curated W2 hookStyle Metadata.

Root cause:
The W2-R style-collapse issue is upstream of slot reservation.

Current behavior:
westernPackAuthor.ts overwrites every W2 pack entry's curated hookStyle with:

hookStyle: pickHookStyle(hookLower)

The pickHookStyle regex is too narrow and falls through to internal_thought for almost every W2 hook. As a result:
- W2 ideas are effectively 100% internal_thought at runtime
- allSameStyle batches stay extremely high
- W2-R hookStyle penalty cannot work because the pool is already monochrome
- raising penalty weights does not solve the problem and risks quality/fallback regression

Goal:
Preserve curated hookStyle metadata from W2 pack entries.

Scope:
Make the smallest safe upstream fix:
- use entry.hookStyle when available
- fall back to pickHookStyle(hookLower) only if entry.hookStyle is missing or invalid

Suggested implementation:
In artifacts/api-server/src/lib/westernPackAuthor.ts, replace:

hookStyle: pickHookStyle(hookLower)

with the equivalent of:

hookStyle: normalizeWesternPackHookStyle(entry.hookStyle) ?? pickHookStyle(hookLower)

or, if the type union already accepts all W2 hookStyle values:

hookStyle: entry.hookStyle ?? pickHookStyle(hookLower)

Before implementation:
1. Verify Idea["hookStyle"] accepts all W2 pack hookStyle values currently used by W2-I/W2-L/W2-N/W2-T.
2. If not, do NOT blindly widen the union.
3. Prefer a small explicit mapping table from W2 hookStyle values to existing Idea hookStyle values only if needed.
4. Report any unsupported values before patching.
