P16-A5 diagnosed a real repetition class:

Add a narrow per-creator memory anti-repeat guard for ng_clean clean-core slot-1+ packing.

- slot-0 quality and existing slot-0 memory behavior
- P16-A3 surfacing

- Do not change slot-0 reservation behavior.
- Do not block all repeats forever.

- Prefer entries not seen recently by the same creator.
- If the candidate pool is too small, gracefully relax the anti-repeat guard rather than underfilling.
- Keep deterministic behavior for tests.
- Preserve existing ranking as much as possible after filtering recent seen IDs.

Recommended behavior:
- For each creator, track recent ng_clean clean-core IDs emitted in slot-1+.
- When selecting slot-1+ clean-core entries, demote or skip IDs seen in the recent window.
- If skipping would underfill, relax and allow best available entry.
- Record emitted slot-1+ clean-core IDs after successful generation.
- Do not record held IDs or rejected IDs.
- Do not record pattern_variation hooks in this memory.

Memory window:
- Start with a small bounded window, for example 12–24 recent IDs per creator.
- Choose the exact size based on existing memory conventions.
